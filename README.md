# 탱고 리듬 트레이너

탱고 음악에 맞춰 **왼발(F)·오른발(J)** 로 리듬과 멜로디를 딛는 연습 게임입니다.

- 게임: https://maximo-tango.github.io/TangoRhythmTrainer/
- 막시모 탱고 회원은 공홈 `/game` 에서 하면 기록과 주간 순위가 남습니다.

## 채보 모드

| 모드 | 내용 |
| --- | --- |
| 박자 easy | 탱고의 기본 걸음에 반박자(doble tiempo)와 싱커페이션을 더한 채보. 피아노·반도네온의 어택을 따라갑니다. |
| 박자 hard | 피아노·반도네온이 치는 **8분음표·16분음표** 리듬까지 딛는 채보. 마디마다 탱고 리듬형(4분·8분·16분 연타·싱코파·3-3-2·하바네라·아라스트레) 중 소리에 가장 맞는 것을 고르고, 같은 선율이 되풀이되는 대목은 같은 리듬이 되게 맞춥니다. |
| 종합 | 박자 걸음에 멜로디를 더한 채보. 바이올린·콘트라베이스·보컬처럼 길게 버티는 음은 **2박·4박 동안 길게 눌렀다 떼는** 노트가 됩니다. |

노트는 계산한 박 자리가 아니라 가까운 실제 피아노·반도네온 어택에 맞춥니다. 두 발을 동시에 누르는 노트는 없고, 왼발·오른발이 번갈아 나옵니다. 길게 누르는 동안 다른 발 노트는 오지 않습니다.

## 채보 만들기 (내 PC)

1. Python 3.10 이상을 설치하고, 처음 한 번 라이브러리를 설치합니다.

   ```
   pip install librosa soundfile numpy mutagen
   ```

2. 이 폴더에 `음원` 폴더를 만들고 mp3 를 넣습니다. (`음원` 폴더는 GitHub 에 올라가지 않습니다)
3. 실행합니다. 곡당 20초쯤 걸립니다.

   ```
   python tango_chart_maker.py
   ```

4. `songs` 폴더에 곡마다 폴더(음원·`beat.json`·`beat_hard.json`·`musical.json`)가 생기고 `songs/index.json` 이 갱신됩니다.
5. 커밋하고 푸시하면 몇 분 뒤 게임 곡 목록에 나옵니다.

곡 이름·악단·가수·연도는 음원 태그에서 읽습니다. 틀린 곡은 `songs/meta.json` 에 곡 id 로 적고 다시 실행하세요.

```json
{ "juan-d-arienzo-derecho-viejo": { "orchestra": "Osvaldo Pugliese" } }
```

분석은 다시 하지 않고 곡 정보만 고치려면 `python tango_chart_maker.py --skip-existing`.
한 곡만 만들려면 `python tango_chart_maker.py "곡.mp3"`.

## 채보 형식

`songs/<곡id>/beat.json`(박자 easy), `beat_hard.json`(박자 hard), `musical.json`(종합)

```json
{ "version": 1, "mode": "beat", "bpm": 64.2, "notes": [[1556, 0, 0, "p", 1], [2647, 1, 0, "h", 0]] }
```

노트 하나 = `[시작ms, 발(0 왼발 · 1 오른발), 끝ms(길게 누르는 노트, 아니면 0), 종류, 강박]`
종류: `p` 기본 걸음(4분) · `h` 반박자(8분) · `q` 16분 · `s` 싱커페이션 · `m` 멜로디(길게). 강박이 1이면 금색 노트.

`songs/index.json` 에는 곡마다 모드별 난이도(`level`, 1분당 판정 수 ÷ 100, 0.7~1.5)도 적습니다. 공홈 게임 곡 목록과 주간 순위가 같은 식을 씁니다.

녹음을 분석해 만드는 것이라 완벽하지 않습니다. 이상한 곳은 json 을 직접 고쳐도 됩니다.
세기 기준 같은 값은 `tango_chart_maker.py` 위쪽 "튜닝 값"에서 조절합니다.
